# create-mira

Creates a new [Mira](https://github.com/buildwithmira/mira) site.

```bash
npm create mira@latest my-site
cd my-site
npm install
npm run dev
```

The site gets the Mira starter template and a `package.json` with `dev` and `build` scripts.
